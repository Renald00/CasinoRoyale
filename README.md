# Casino Royale - Card & Table Games

A multiplayer casino games application featuring classic card games, horse racing, and dice games.

## Games Included

### 🃏 Blackjack
- Classic card game against the dealer
- Hit, Stand, and try to beat the dealer to 21
- Supports 2-8 players

### ♠ Poker (5-Card Draw)
- Classic poker with betting and card drawing
- Bet, fold, or draw new cards
- Hand rankings from High Card to Royal Flush

### ⚔️ War
- Simple card comparison game
- Higher card wins the round
- Best of all rounds wins

### 🏇 Karera (Horse Racing)
- Filipino-style horse racing betting game
- 6 horses to bet on with 5x payout
- Animated race with real-time updates

### 🎲 Dice (Craps)
- Classic dice game with multiple bet types
- Pass Line, Don't Pass, Field, Any 7, Any Craps
- Animated dice rolling

### 🎴 Solitaire
- Classic Klondike solitaire
- Single-player card game
- Build foundations from Ace to King

## Controls

- **Click** cards to select/deselect
- **Hit/Stand** buttons for Blackjack
- **Bet/Fold/Draw** buttons for Poker
- **Play Card** button for War
- **Select horse + chips** for Karera
- **Select bet type + chips + Roll** for Dice
- **Click** to move cards in Solitaire

## Setup

```bash
npm install
npm start
```

Server runs on http://localhost:3000

## How to Play

1. Enter your name
2. Select a game
3. Create a room or join with a code
4. Wait for players (or play Solitaire alone)
5. Start the game and enjoy!

## Features

- Real-time multiplayer with Socket.io
- Beautiful UI with particle effects
- Responsive design for all devices
- Animated cards and dice
- Horse racing with live tracking
